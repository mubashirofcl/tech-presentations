Foundations of GenAI

What Is Generative AI?

✨ Definition

Generative AI is a type of AI that can create new, original content based on patterns learned from training data.

⚙️ How Does It Work? (4 Steps)

1. Training: A model is trained using vast amounts of text, code, or images.
2. Pattern Recognition: It learns mathematical representations and semantic relationships.
3. Prompt Input: A user provides an instruction called a prompt.
4. Token Generation: The model generates a novel response based on that prompt.
⚠️ Important: Generative AI does not simply copy and paste its training data. It generates outputs based on learned statistical patterns, although outputs can sometimes resemble existing content.

📋 Input vs Generated Output Examples

User Prompt (Input) Generated Output Modality
"Write a story about a robot" Original narrative paragraph Text
"Generate a logo for a coffee brand" High-resolution vector/PNG Image
"Convert this blog text into speech" Lifelike synthetic voiceover Audio
"Describe a video scene of a rainy city" Dynamic animated clip Video
"Write a JavaScript function to sort students" Clean, executable JS code Code

Core Technology

What Is an LLM? (Large Language Model)

📖 Definition

An LLM (Large Language Model) is an artificial intelligence model trained on vast amounts of text and code data to understand, reason over, and generate human-like language.

🌐 Prominent Industry Models

OpenAI: GPT-4o, GPT-4.1-mini, o1
Anthropic: Claude 3.5 Sonnet, Claude 3 Haiku
Google: Gemini 2.5 Flash, Gemini 1.5 Pro
Meta: Llama 3.1, Llama 3.3 (Open Weights)

⚙️ What Can an LLM Do?

Answer questions, write essays, summarize documents, translate 50+ languages, explain complex code, and generate production APIs.

🔬 How Does an LLM Work?

  1. Receives input text from the user.
  2. Breaks the input text down into numerical tokens.
  3. Processes tokens through transformer neural layers and attention weights.
  4. Predicts the most probable next token sequentially.
  5. Assembles tokens into human-readable text and returns the response.

🔑 3 Critical Terms

Token: A chunk of characters (approx 4 characters or 0.75 words). "Hello world" = 2 tokens.
Prompt: The instructions, context, or question passed to the model.
Context Window: The maximum number of tokens a model can hold in memory at one time.
💡 Core Insight: LLMs are next-token prediction engines guided by context and probability!

Hands-on Execution

Practical: Send a Prompt to an LLM

server.js (askAI Function) 
require("dotenv").config();
const OpenAI = require("openai");

const client = new OpenAI({
    apiKey: process.env.OPENAI_API_KEY
});

// Reusable function to prompt the LLM
async function askAI(question) {
    const response = await client.responses.create({
        model: "gpt-4.1-mini",
        input: question
    });

    return response.output_text;
}

async function main() {
    console.log("Asking AI...");
    const answer = await askAI("Explain Node.js in simple words");
    console.log("\nAI Answer:\n", answer);
}

main();
▶ Run: node server.js

⚙️ Execution Flow

  1. askAI() takes a string prompt.
  2. client.responses.create() makes an HTTPS call to OpenAI.
  3. The model evaluates tokens and generates completions.
  4. response.output_text contains the generated answer text.

Guiding the Model

What Is Prompt Engineering?

📖 Definition

A prompt is the instruction or input given to an AI model. Prompt engineering is the practice of designing structured, unambiguous instructions to obtain accurate, relevant, and consistent outputs.

❌ Example 1: Basic Prompt (Too Vague)

"Explain JavaScript."

Problem: The model doesn't know the audience, desired depth, or formatting.

✅ Example 2: Engineered Prompt (Effective)

"You are a JavaScript teacher. Explain JavaScript to a complete beginner. Use simple English. Give three practical examples. Keep the explanation short."

🔑 Why Does the Second Prompt Win?

1. Persona / Role: "You are a JavaScript teacher."
2. Target Audience: "to a complete beginner."
3. Specific Task: "Give three practical examples."
4. Constraints: "Use simple English. Keep the explanation short."
Using Instructions in OpenAI SDK 
// Using system instructions in responses.create
const response = await client.responses.create({
    model: "gpt-4.1-mini",
    instructions: "You are a beginner-friendly Node.js teacher.",
    input: "Explain Express middleware with an example."
});

console.log(response.output_text);

Backend API Development

Practical: Build a Basic GenAI API

server.js (Express POST /ask) 
require("dotenv").config();
const express = require("express");
const OpenAI = require("openai");

const app = express();
app.use(express.json());

const client = new OpenAI({
    apiKey: process.env.OPENAI_API_KEY
});

// POST /ask endpoint
app.post("/ask", async (req, res) => {
    try {
        const { question } = req.body;

        if (!question) {
            return res.status(400).json({
                message: "Question is required"
            });
        }

        const response = await client.responses.create({
            model: "gpt-4.1-mini",
            input: question
        });

        res.json({
            success: true,
            answer: response.output_text
        });
    } catch (error) {
        console.error(error);
        res.status(500).json({
            success: false,
            message: "AI request failed"
        });
    }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => console.log(`GenAI server running on ${PORT}`));
▶ Run: node server.js

Advanced Architectures

What Is RAG? (Retrieval-Augmented Generation)

📚 Definition

RAG (Retrieval-Augmented Generation) is an architecture that allows an LLM application to retrieve relevant information from an external knowledge source before generating an answer.

❓ Why Do We Need RAG?

Base LLMs are frozen in time and have knowledge cutoffs. They do not know:

• Your company's internal private documents.
• Your latest live product releases or pricing.
• Uploaded customer PDF contracts or receipts.

Without RAG, asking about private data causes the model to hallucinate (invent false facts)!

📊 The 2-Phase RAG Architecture

Phase 1: Knowledge Ingestion
DocumentsPDF / Docs
→

→
EmbeddingsVector math
→
Vector DBStorage
Phase 2: Query & Augmented Generation

RAG in Action

Practical: Simple RAG Concept in Node.js

simpleRag.js 
// 1. Simulated external knowledge base
const knowledge = [
    "Node.js is a JavaScript runtime built on Chrome's V8 engine.",
    "Express.js is a lightweight web framework for Node.js backend APIs.",
    "MongoDB is a NoSQL document database that stores JSON-like records."
];

// 2. Retrieval step: search relevant info
function retrieveContext(question) {
    return knowledge.filter(item =>
        question.toLowerCase().includes("node") &&
        item.toLowerCase().includes("node")
    );
}

// 3. Augment prompt with retrieved context
async function askWithContext(question) {
    const context = retrieveContext(question);

    const response = await client.responses.create({
        model: "gpt-4.1-mini",
        instructions: `
            Answer using the provided context.
            If the answer is not available,
            say that you do not have enough information.
        `,
        input: `
            Context:
            ${context.join("\n")}

            Question:
            ${question}
        `
    });

    return response.output_text;
}

🔄 Understand the Flow

Question → Retrieve Relevant Information → Add Context to Prompt → Send to LLM → Generate Factual Answer.

⚠️ Classroom Note: This is a simplified keyword-matching demonstration. Production RAG systems use semantic embeddings, chunking, and vector databases like Pinecone or ChromaDB.

Autonomous Systems

What Is an AI Agent?

🤖 What Is an AI Agent?

An AI Agent is an AI-powered system that can work toward an autonomous goal by deciding what steps to take and executing available tools.

💡 Chatbot vs Agent: Unlike a basic chatbot that only talks, an agent interacts with external systems to perform tasks!

📋 Concrete Scenario

User asks: "Find my pending tasks and create a reminder for tomorrow."

  1. Understand the user's intent.
  2. Identify required actions.
  3. Call task-list tool: getTasks().
  4. Inspect pending tasks.
  5. Call reminder tool: createReminder().
  6. Confirm completion back to user.

🔄 Autonomous Agent Architecture

1. User Goal Request "Book a meeting with Arun"
↓
2. LLM Thinks & Decides Needs calendar availability
↓
3. Request Tool Execution Calls checkCalendar({ user: 'Arun' })
↓
4. Backend Runs Function Returns available slot: 3 PM
↓
5. LLM Formulates Final Answer "Meeting scheduled for 3 PM!"
Hands-on Function Execution

Practical: Understanding Tool Calling

toolExecution.js (Node.js Tools) 
// 1. Real Node.js function exposed as a tool
function getStudentDetails(studentId) {
    const students = [
        { id: 1, name: "Arun", course: "MERN" },
        { id: 2, name: "Meera", course: "GenAI" }
    ];

    return students.find(s => s.id === studentId);
}

// 2. Dispatcher that executes tool requested by AI
function executeTool(toolName, input) {
    if (toolName === "getStudentDetails") {
        return getStudentDetails(input.studentId);
    }
    return "Tool not found";
}

// Simulated tool execution
const result = executeTool("getStudentDetails", { studentId: 2 });
console.log(result);
// Output: { id: 2, name: "Meera", course: "GenAI" }

⚙️ How Real AI Tool Calling Works

  1. The LLM decides a tool is needed to answer a question.
  2. The LLM returns a structured JSON tool call with arguments.
  3. Your Node.js backend validates the arguments and runs the JS function.
  4. The tool result is sent back to the LLM to complete its answer.

What Is Multimodal AI?

🌐 Definition

Multimodal AI refers to AI systems that can process, reason across, or generate information across multiple distinct data modalities (Text, Images, Audio, Video) in a unified model.

🖼️
Text + Image

Upload a photo of a receipt → "What is the total amount?"

🎙️
Text + Audio

User speaks a question → receives an immediate spoken voice reply.

🎬
Video + Text

Upload a 2-minute video → "Summarize what happens in this clip."

⚠️ Note: Model capabilities differ by provider. Not every model supports image, audio, or video inputs.
multimodalExample.js (Text + Image) 
// Sending text + image input to a multimodal model
const response = await client.responses.create({
    model: "gpt-4.1-mini",
    input: [{
        role: "user",
        content: [
            {
                type: "input_text",
                text: "Describe this image and identify the main objects."
            },
            {
                type: "input_image",
                image_url: "https://example.com/sample-diagram.jpg"
            }
        ]
    }]
});

console.log(response.output_text);
