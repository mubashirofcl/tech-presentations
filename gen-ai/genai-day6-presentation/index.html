What Is an SDK? Introduction to Groq SDK

Eliminating boilerplate HTTP headers, manual parsing, and authentication with official SDK clients.

📦
Why Developers Use SDKs

An SDK is a collection of helper functions and classes provided by an API vendor to simplify network communication.

  • Without SDK: You must manually write fetch(), construct Authorization: Bearer headers, format JSON strings, parse streams byte-by-byte, and handle network retries manually.
  • With SDK: You call clean, typed methods like groq.chat.completions.create().

Golden Security Rules
  • Never Hardcode Keys: Never write apiKey: "gsk_xxxx" inside source code files.
  • Never Commit .env: Always include .env in your .gitignore before running git commit.
  • Keep on Backend: Never expose API keys to React or browser frontend bundles.

Module 4 • Parameters 08 / 20

Temperature: Control Response Randomness

Calibrating output variance between deterministic precision and creative brainstorming.

🌡️
Low vs High Temperature
  • Low Temperature (e.g. 0.2): Highly focused, deterministic, minimal variation. Essential for JSON extraction, SQL queries, and factual coding.
  • High Temperature (e.g. 1.2): Diverse, unexpected word pairings, creative brainstorming.
  • Groq Range: Supports 0.0 to 2.0 for Chat Completions.
💡
Critical Insight
Higher temperature does not make the model smarter! It increases token selection entropy (randomness), not cognitive capability.

Module 4 • Parameters 09 / 20

Maximum Completion Tokens

Setting output ceilings with max_completion_tokens to prevent runaway generation.

🔢
Token Limits & Deprecation
  • What are Tokens? Units of text (~4 characters or 0.75 words in English).
  • Context Window: Total tokens allowed for Prompt + Completion combined.
  • max_completion_tokens: Upper ceiling specifically on generated output tokens.
  • Technical Notice: Groq documents max_completion_tokens as the active parameter; max_tokens is deprecated.
⚠️
Finish Reason: Length
If max_completion_tokens is set too low, the model abruptly halts mid-sentence with finish_reason: "length".

TRY / CATCH ERROR HANDLING
async function askAI(question) {
  try {
    const res = await groq.chat.completions.create({
      model: process.env.GROQ_MODEL,
      messages: [{ role: "user", content: question }]
    });
    return res.choices[0].message.content;
  } catch (error) {
    console.error("Groq Error:", error.message);
    if (error.status === 401) return "Invalid API key.";
    if (error.status === 429) return "Rate limit exceeded. Try later.";
    return "AI service temporarily unavailable.";
  }
}

Real-Time Streaming Response

⚡

💬
ChatGPT-Style UX

💡
Crucial Nuance

Streaming does not make the model compute faster; it lets users see partial progress earlier!

Module 7 • Streaming 16 / 20

Node.js Practical: Create a Streaming LLM API

Implementing POST /chat/stream using stream: true and for await...of in Express.

EXPRESS ROUTE • POST /chat/stream 
app.post("/chat/stream", async (req, res) => {
  try {
    const { question } = req.body;
    if (!question) return res.status(400).json({ error: "Question is required" });

    // 1. Initialize SSE Response Headers
    res.setHeader("Content-Type", "text/event-stream");
    res.setHeader("Cache-Control", "no-cache");
    res.setHeader("Connection", "keep-alive");

    // 2. Request stream from Groq SDK
    const stream = await groq.chat.completions.create({
      model: process.env.GROQ_MODEL,
      messages: [{ role: "user", content: question }],
      stream: true
    });

    // 3. Iterate over async stream and write SSE frames
    for await (const chunk of stream) {
      const token = chunk.choices[0]?.delta?.content || "";
      if (token) {
        res.write(`data: ${JSON.stringify({ token })}\n\n`);
      }
    }

    res.write("data: [DONE]\n\n");
    res.end();
  } catch (error) {
    console.error("Streaming Error:", error.message);
    if (res.headersSent) {
      res.write(`event: error\ndata: ${JSON.stringify({ message: "Streaming failed" })}\n\n`);
      return res.end();
    }
    res.status(500).json({ error: "AI streaming failed" });
  }
});
Module 7 • Streaming 17 / 20

Practical: Receive Streaming Data in Frontend

Consuming raw chunk buffers reliably with ReadableStream and TextDecoder.

FRONTEND STREAM CONSUMER
const response = await fetch("http://localhost:3000/chat/stream", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ question: "Explain Node.js" })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();
let buffer = "";

while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true });
  
  // Split complete SSE frames on \n\n
  const events = buffer.split("\n\n");
  buffer = events.pop(); // Keep trailing incomplete frame

  for (const event of events) {
    const line = event.split("\n").find(l => l.startsWith("data: "));
    if (!line) continue;
    const data = line.slice(6);
    if (data === "[DONE]") return;
    answerDiv.textContent += JSON.parse(data).token;
  }
}

Module 8 • Cost & Budget 19 / 20

Cost Awareness: How to Control LLM Usage

Understanding token pricing formulas and applying 8 architectural controls to curb runaway spend.

💰
Token Cost Calculation Model

Standard token pricing calculates input and output tokens separately per million tokens:

Total Cost = (Input Tokens / 1M × Rate) + (Output Tokens / 1M × Rate)
  • Limit History: Don't resend 50 past chat turns on every message.
  • Cap Output: Always configure max_completion_tokens.
  • Cache Responses: Use Redis to serve identical queries instantly.
  • Tier Selection: Use smaller 8B models for simple tasks and 70B for reasoning.

Capstone Solution • groq-ai-app/server.js
JAVASCRIPT • server.js (Complete Implementation)
require("dotenv").config();
const express = require("express");
const Groq = require("groq-sdk");

const app = express();
app.use(express.json());

const groq = new Groq({
  apiKey: process.env.GROQ_API_KEY,
  maxRetries: 2,
  timeout: 20000
});

const MODEL = process.env.GROQ_MODEL || "llama-3.3-70b-versatile";

// Health check
app.get("/", (req, res) => {
  res.send("Groq AI Server is running!");
});

// Normal AI request
app.post("/chat", async (req, res) => {
  try {
    const { question, temperature = 0.7 } = req.body;

    if (typeof question !== "string" || !question.trim()) {
      return res.status(400).json({ error: "Valid question is required" });
    }

    if (typeof temperature !== "number" || temperature < 0 || temperature > 2) {
      return res.status(400).json({ error: "Temperature must be between 0 and 2" });
    }

    const response = await groq.chat.completions.create({
      model: MODEL,
      messages: [
        { role: "system", content: "You are a helpful AI assistant." },
        { role: "user", content: question }
      ],
      temperature,
      max_completion_tokens: 300
    });

    res.json({
      success: true,
      answer: response.choices[0].message.content,
      usage: response.usage
    });
  } catch (error) {
    console.error("Groq API Error:", error.message);
    const status = error.status === 429 ? 429 : 502;
    res.status(status).json({ success: false, error: "Unable to generate AI response" });
  }
});

// Streaming AI request (SSE)
app.post("/chat/stream", async (req, res) => {
  try {
    const { question } = req.body;

    if (typeof question !== "string" || !question.trim()) {
      return res.status(400).json({ error: "Valid question is required" });
    }

    res.setHeader("Content-Type", "text/event-stream");
    res.setHeader("Cache-Control", "no-cache");
    res.setHeader("Connection", "keep-alive");

    const stream = await groq.chat.completions.create({
      model: MODEL,
      messages: [{ role: "user", content: question }],
      stream: true
    });

    for await (const chunk of stream) {
      const token = chunk.choices[0]?.delta?.content || "";
      if (token) {
        res.write(`data: ${JSON.stringify({ token })}\n\n`);
      }
    }

    res.write("data: [DONE]\n\n");
    res.end();
  } catch (error) {
    console.error("Streaming Error:", error.message);
    if (res.headersSent) {
      res.write(`event: error\ndata: ${JSON.stringify({ message: "Streaming failed" })}\n\n`);
      return res.end();
    }
    res.status(502).json({ error: "Unable to stream AI response" });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});
