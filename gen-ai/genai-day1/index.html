Fundamental Concepts

What is Generative AI?

📖 Definition

Generative AI is a type of AI that creates new, original content (text, images, audio, video, code) by learning patterns from large amounts of existing data.

🔑 Key Terms

Model: The trained “brain” that generates output (e.g., Gemini, GPT).
Prompt: The instruction or question you provide to the model.
Token: A small piece of text (a word or partial word) that the model reads and writes.
LLM (Large Language Model): A GenAI model trained on vast text data to understand and generate human language.

⚙️ How It Works

Prompt → Model predicts the next token, repeatedly → Output
The model reads your prompt and calculates probabilities to predict the most likely next token, step by step, until the answer is complete.

💡 Real Example: You prompt: “Write a leave letter for fever” → The model generates a unique, tailored letter. It does not look up or copy one from a database.

Conceptual Hierarchy

AI vs ML vs DL vs GenAI

🧠 Definitions & Scope

AI (Artificial Intelligence): Any technique that enables machines to perform tasks requiring human-like intelligence.
Example: Chess bot, Google Maps finding the fastest route.
ML (Machine Learning): A subset of AI where machines learn patterns from data instead of being explicitly programmed.
Example: Gmail spam filter learning from marked spam.
DL (Deep Learning): A subset of ML that uses multi-layer neural networks to learn complex representations from massive data.
Example: Face unlock on phones, YouTube voice-to-caption.
GenAI (Generative AI): A subset of DL that generates new, original content instead of merely classifying or predicting.
Example: ChatGPT writing an essay, Gemini generating images.
💡 One-Line Memory Trick:
AI = thinks · ML = learns · DL = learns deeply · GenAI = creates
Term Meaning Real-World Example
AI Machines doing “smart” tasks Chess bot, route planning
ML Learns patterns from data Spam filter, movie recommendations
DL ML using deep neural networks Face unlock, autonomous driving vision
GenAI DL that generates new content ChatGPT, Gemini, Midjourney

Comparative Analysis

Traditional AI vs Generative AI

⚖️ Key Differences

Traditional AI: Systems built for one specific task that analyze data and produce a fixed output (a label, numerical score, or classification).
Example: A bank fraud detector says “Fraud / Not Fraud”. It cannot draft an explanation email.

Generative AI: General-purpose foundation models that create original content and solve diverse tasks across domains using natural language prompts.
Example: The same Gemini model can summarize a PDF, write Node.js code, and translate text.

💡 Core Distinction: Traditional AI answers “Which one?” whereas GenAI answers “Make one.”
Feature Traditional AI Generative AI
Goal Classify / predict Create new content
Output Label or number Text, image, code, audio…
Built With Rules or task-specific models Large pretrained models + prompts
Flexibility One narrow task Many diverse tasks

💡 Code Demo Insight

Rule-based code looks for the substring 'bad' and incorrectly classifies "The food was not bad at all!" as Negative. GenAI understands nuanced semantics and correctly detects Positive sentiment!

System Architecture 1 of 3

Architecture 1: Direct LLM App

🏛️ Architecture Definition

The simplest GenAI pattern where your backend receives a user’s prompt, forwards it directly to an LLM API, and returns the generated response to the frontend client.

Data Flow Pipeline

📱 Client (Browser/App)
→
🚀 Node/Express API (/ask)
→
🧠 Gemini LLM
→
📥 JSON Response

🔒 Why Do We Need a Backend?

API Key Security: Never expose your GEMINI_API_KEY in browser code. The Node.js server securely signs requests while providing rate limiting, logging, and user authentication.

When to use: General tasks like text editing, translation, grammar fixing, creative writing.
Limitation: The LLM only knows its training cutoff data. It cannot access proprietary company records or real-time information.
📄 demos/05-llm-api.js
Express.js API 
// 05-llm-api.js
import express from 'express';
import { ai, MODEL } from './ai.js';

const app = express();
app.use(express.json());

  res.json({ answer: r.text });

app.listen(3000, () => console.log('http://localhost:3000'));

Architecture 2: RAG Pipeline

📚 Retrieval-Augmented Generation

RAG fetches relevant information from your own database first, then provides that retrieved context to the LLM. This prevents hallucination and grounds answers in factual company data.

1. Ingestion & 2. Query Pipeline

📄 Private Docs
→
🔢 Embeddings
→
🗄️ Vector Store
❓ User Question
→
📐 Cosine Match
→
🧠 LLM + Context
→
🎯 Accurate Answer

🔑 Core Concepts

Embedding: A numerical vector representing the semantic meaning of text.
Cosine Similarity: Mathematical metric calculating angle between two vectors (1 = identical meaning).
Hallucination: When an LLM confidently invents untrue facts. RAG eliminates this by restricting generation to retrieved context.
📄 demos/06-rag.js
Embed + Search 
// 06-rag.js
import { ai, MODEL } from './ai.js';

const docs = [
  'Classes run Monday to Friday, 10 AM to 1 PM.',
  'Placement support starts after course completion.',
  'Students get lifetime access to recorded sessions.',
];

const embed = async (texts) =>
  (await ai.models.embedContent({ model: 'gemini-embedding-001', contents: texts }))
    .embeddings.map(e => e.values);

const cosine = (a, b) => {
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) { dot += a[i] * b[i]; na += a[i] ** 2; nb += b[i] ** 2; }
  return dot / Math.sqrt(na * nb);
};

const question = 'What time are the classes?';
const docVecs = await embed(docs);           // 1. Index
const [qVec] = await embed([question]);      // 2. Embed question
const scores = docVecs.map(v => cosine(qVec, v));
const best = docs[scores.indexOf(Math.max(...scores))]; // 3. Retrieve
console.log('Retrieved:', best);

const res = await ai.models.generateContent({  // 4. Generate
  model: MODEL,
  contents: `Answer only from this context:\n${best}\n\nQuestion: ${question}`,
});
console.log('Answer:', res.text);
▶ Run: node demos/06-rag.js
System Architecture 3 of 3

Architecture 3: Autonomous AI Agent

🤖 What is an AI Agent?

An AI Agent is an LLM that autonomously decides which actions to take, calls external tools (functions/APIs), observes results, and loops until it completes a high-level goal.

💡 LLM App vs Agent: An LLM App only talks; an Agent talks and acts!
STEP 01 🎯 Goal Prompt "Should I carry an umbrella in Kochi?"
STEP 02 🧠 LLM Thinks Decides it needs weather data
STEP 03 🔧 Call Tool Invokes getWeather({ city: 'Kochi' })
STEP 04 🔄 Loop & Output Receives "Rainy" & formulates final answer

🔑 Key Agent Mechanics

Function Declarations: Giving the model a schema of your code tools.
Agent Loop: Think → Act (execute tool) → Observe result → Repeat until objective resolved.
📄 demos/07-agent.js
Tool Calling Loop 
// 07-agent.js
import { ai, MODEL } from './ai.js';

const tools = {
  getWeather: ({ city }) => ({ city, temp: '31°C', sky: 'Rainy' }), // fake tool
};

const config = {
  tools: [{
    functionDeclarations: [{
      name: 'getWeather',
      description: 'Get current weather for a city',
      parameters: { type: 'object', properties: { city: { type: 'string' } }, required: ['city'] },
    }],
  }],
};

const contents = [{ role: 'user', parts: [{ text: 'Should I carry an umbrella in Kochi today?' }] }];

while (true) {
  const res = await ai.models.generateContent({ model: MODEL, contents, config });
  if (!res.functionCalls?.length) { console.log('Agent:', res.text); break; }

  contents.push(res.candidates[0].content);
  for (const call of res.functionCalls) {
    console.log('🔧 Tool call:', call.name, call.args);
    const result = tools[call.name](call.args);
    contents.push({ role: 'user', parts: [{ functionResponse: { name: call.name, response: result } }] });
  }
}
▶ Run: node demos/07-agent.js
Next-Gen Capabilities

Multimodal Artificial Intelligence

🌐 Definition & Modalities

Multimodal AI can understand, reason over, and combine multiple input modalities (text, images, audio, video) simultaneously inside a unified model.

🔄 Unimodal vs Multimodal

Unimodal (Legacy): Text in → Text out. Models could only parse text tokens.
Multimodal (Modern): Image + Text in → Text out (or Image/Audio out). Visual features and tokens share unified embedding space.

🚀 Real-World Examples

  • Photo of a damaged bicycle part + “What is this and how do I replace it?”
  • Google Lens: Translating street signboards in foreign languages.
  • Photographing handwritten mathematical equations to receive step-by-step solutions.
  • Leading Models: Gemini 2.5 Flash, GPT-4o, Claude 3.5 Sonnet.
