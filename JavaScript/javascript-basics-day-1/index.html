Declaration Keywords

var, let, and const

Understanding reassignment, scope boundaries, and modern best practices

VAR VS LET VS CONST
🔍 The Three Declaration Keywords
1. var (Legacy) Function-scoped. Can be reassigned and redeclared. Avoid in modern code.
2. let (Mutable) Block-scoped {}. Can be reassigned, but NOT redeclared.
3. const (Default) Block-scoped. Constant reference: CANNOT be reassigned!
Featurevarletconst
Can Reassign?✅ Yes✅ Yes❌ No
Can Redeclare in same scope?✅ Yes❌ No❌ No
Block Scope { }?❌ No (Function)✅ Yes✅ Yes
Must Initialize on Declare?❌ Optional❌ Optional✅ Required
🏆 Modern JavaScript Rule of Thumb:

Use const by default everywhere. Use let only when you know a variable's value must be reassigned (like loop counters). Never use var!

Outputting Data

Return Statement

Sending calculated results back to the caller instead of just logging

RETURN VS LOG
❌ Direct Logging (console.log)

Displays output to the console, but does not give a value back to your code:

justLogging.js
function add(a, b) {
  console.log(a + b);
}

const result = add(10, 20); // Logs 30
console.log(result);        // undefined!

Because there was no return, result receives undefined. You cannot perform further calculations with it!

✅ Returning Values (return)

Gives the result back to the caller so it can be stored, passed to other functions, or transformed:

withReturn.js
function add(a, b) {
  return a + b; // Ends function & sends value
}

const total = add(10, 20);
console.log(total * 2); // 60
Terminal Output:
60
Immediate Exit: Once a function hits return, execution terminates immediately. Any code below the return statement is ignored.

Key Operators

Understanding Modulus and Increment

Even/odd detection with % and mutating counters with ++ and --

MODULUS & INCREMENT
🔢 1. Modulus (%) – The Remainder

Returns the remainder left over when one integer is divided by another:

evenOdd.js
function checkNumber(num) {
  if (num % 2 === 0) {
    return "Even Number";
  }
  return "Odd Number";
}

console.log(checkNumber(10)); // Even Number
console.log(checkNumber(7));  // Odd Number
Terminal Output:
Even Number Odd Number
📈 2. Increment (++) & Decrement (--)

Quickly adds or subtracts 1 from a variable (frequently used in loops):

counterMutation.js
let count = 5;

count++; // Same as count = count + 1
console.log(count); // 6

count--; // Same as count = count - 1
console.log(count); // 5
Note for Python Developers: Python does not support count++ (you had to write count += 1). In JavaScript, ++ is a standard, highly popular shorthand!
Order of Operations

Operator Precedence

Predicting execution order and using parentheses to guarantee clarity

PRECEDENCE
⚖️ Order of Operations (PEMDAS)

Just like in algebra and Python, multiplication & division happen before addition & subtraction:

precedence.js
// Multiplication runs first: 5 * 2 = 10 ➔ 10 + 10 = 20
const result1 = 10 + 5 * 2;
console.log(result1); // 20

// Parentheses override precedence: (10 + 5) = 15 ➔ 15 * 2 = 30
const result2 = (10 + 5) * 2;
console.log(result2); // 30
Clean Code Rule: Always use parentheses ( ) when writing multi-step formulas so your teammates understand your intention immediately!

Practical: Build a Unit Converter

Formulas for temperature and distance conversion in modular functions

UNIT CONVERTER
unitConverter.js
// 1. Celsius to Fahrenheit: F = (C × 9/5) + 32
function celsiusToFahrenheit(c) {
  return (c * 9 / 5) + 32;
}

// 2. Fahrenheit to Celsius: C = (F - 32) × 5/9
function fahrenheitToCelsius(f) {
  return (f - 32) * 5 / 9;
}

// 3. Kilometers to Miles: Miles = km × 0.621371
function kmToMiles(km) {
  return km * 0.621371;
}

console.log(celsiusToFahrenheit(25)); // 77
console.log(fahrenheitToCelsius(77)); // 25
console.log(kmToMiles(10));           // 6.21371

Variable Visibility

What Is Scope?

Understanding Global, Function, and Block Scope in JavaScript

SCOPE BOUNDARIES
🌍 1. Global Scope

Declared outside any function or block. Accessible anywhere:

const name = "Arun";

function greet() {
  console.log(name); // OK!
}

greet();
console.log(name);   // OK!
📦 2. Function Scope

Declared inside a function. Cannot be read from outside:

function test() {
  let age = 22;
  console.log(age); // OK
}

test();
// ReferenceError: age is not defined
// console.log(age);
🧱 3. Block Scope {}

let and const are trapped inside curly braces { }:

if (true) {
  var a = 10;  // Leaks!
  let b = 20;  // Trapped
}

console.log(a); // 10
// ReferenceError: b is not defined
// console.log(b);
⚠️ The Huge Takeaway for Python Students:

In Python, if blocks and for loops do NOT create a new scope. In JavaScript, let and const strictly confine variables to the enclosing { } block!

Advanced Fundamentals

What Is a Closure?

How inner functions remember variables from their outer scope even after execution ends

CLOSURES
🧠 The Lexical Environment Remembered

A closure occurs when an inner function retains access to its parent function's variables, even after the parent function has finished executing!

counterClosure.js
function createCounter() {
  let count = 0; // Private, encapsulated state

  return function() {
    count++;     // Accesses outer 'count'
    return count;
  };
}

const counter = createCounter();

console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
Data Encapsulation: count cannot be altered from outside
React State Precursor: Underpins React Hooks like useState

Final Practical: Utility Calculator

Combining variables, arithmetic operators, functions, scope, and closures into one program

PROJECT & ASSIGNMENT
utilityCalculator.js
// 1. Math Calculator
function calculate(a, b, op) {
  if (op === "+") return a + b;
  if (op === "-") return a - b;
  if (op === "*") return a * b;
  if (op === "/") return b === 0 ? "Cannot divide by zero" : a / b;
  return "Invalid operator";
}

// 2. Unit Converter
const celsiusToFahrenheit = c => (c * 9 / 5) + 32;
const kmToMiles = km => km * 0.621371;

// 3. Closure Counter
function createCounter() {
  let count = 0;
  return () => ++count;
}
const counter = createCounter();

// Tests
console.log(calculate(10, 5, "+"));        // 15
console.log(celsiusToFahrenheit(25));      // 77
console.log(kmToMiles(10));                // 6.21371
console.log(counter(), counter());         // 1, 2
