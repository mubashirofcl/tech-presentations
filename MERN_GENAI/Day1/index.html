Section 1 • Foundations

What Is Generative AI?

Definition & Fundamental Concept

Generative AI is a category of artificial intelligence that creates new, original content based on patterns learned from vast datasets and the input instructions it receives.

  • 1. Text Generation Conversational responses, technical documentation, marketing copy, and automated emails.
  • 2. Code Generation Complete functions, bug explanations, unit test suites, and schema boilerplate.
  • 3. Multimodal Media High-fidelity images, UI mockups, realistic speech audio, and video synthesis.
Core Mental Model: Traditional software strictly executes pre-written if/else rules. Generative AI generates novel, context-aware content based on probabilistic neural patterns.
Everyday Industry Examples
ChatGPT General reasoning, text generation, and customer assistance.
GitHub Copilot Real-time code completions, inline refactoring, and bug fixes.
Midjourney / DALL-E Visual design assets, concept art, and photo synthesis.
AI Voice Agents Human-like customer support calls and real-time audio translation.
Section 1 • Foundations

AI vs ML vs DL vs Generative AI

Understanding the Technology Hierarchy
  • 1. Artificial Intelligence (AI) The overarching discipline of creating software and machines that perform tasks requiring human intelligence.
  • 2. Machine Learning (ML) A subset of AI where systems automatically learn patterns from data instead of being explicitly programmed.
  • 3. Deep Learning (DL) A subset of ML powered by multi-layered neural networks inspired by human brain biology.
  • 4. Generative AI (GenAI) Deep learning architectures (like Transformers) optimized specifically to generate new output content.

Section 2 • LLM Concepts

What Is an LLM (Large Language Model)?

Definition & Capabilities

An LLM is a deep learning model trained on terabytes of text from the internet, books, and code repositories to predict and generate natural human language.

  • What Can an LLM Do? Answer complex questions, write programming code, summarize documents, translate languages, and extract structured data.
  • Prominent Frontier LLMs GPT-4o / GPT-4.1 (OpenAI), Gemini 2.5 (Google), Claude 3.5 (Anthropic), Llama 3.2 (Meta).

Section 2 • Tokens & Limits

Tokens, Context Window & Hallucinations

Tokens: The Language of LLMs

An LLM does not read whole words or characters directly. Text is sliced into tokens (chunks of ~4 characters or ¾ of an English word).

"MERN Stack builds fast APIs" → ["M", "ERN", " Stack", " builds", " fast", " APIs"]
Context Window

The total token budget (input prompt + generated output) that a model can process in one call. Exceeding it triggers truncation or API errors!

Hallucinations & Model Limitations

A hallucination occurs when an LLM generates plausible-sounding information that is factually incorrect or completely invented.

  • Why it happens: The model generates the next statistically likely word, not a verified database query!
  • Knowledge Cutoff: The model does not know events or libraries released after its training date unless provided in the prompt.
  • Developer Defense: Always validate critical responses, provide grounding context, and avoid blindly trusting raw outputs!

Section 3 • Prompt Engineering

What Is Prompt Engineering?

The Art & Science of Guiding AI

Prompt Engineering is the process of crafting and structuring instructions so an AI model returns predictable, relevant, and format-compliant results.

  • Why it matters: Small changes in prompt wording create massive differences in response quality.
  • Reduces Fluff: Eliminates boilerplate conversation and forces concise answers.
  • Enforces Consistency: Guarantees output formats needed by downstream Node.js code.
Weak Prompt
"Explain JavaScript."
× Too broad, unpredictable length, no audience specified.
Better Prompt
"Explain JavaScript to a beginner in simple English. Include three important features and one practical example."
✓ Specific audience, structured deliverables, actionable format!
Section 3 • Prompt Anatomy

Anatomy of a Good Prompt

5 Essential Components
  • 1. Role: Who the AI should act as (e.g. "Experienced Node.js teacher").
  • 2. Task: What the AI must do (e.g. "Explain Express middleware").
  • 3. Context: What background it knows (e.g. "Student knows JavaScript basics").
  • 4. Instructions: Steps to follow (e.g. "Use simple English and code").
  • 5. Constraints: Rules/Limits (e.g. "Under 200 words, CommonJS only").

          Section 5 • AI Chat API
          
Practical: Build POST /api/chat

        


        

          

            

              

                

                  

                  server.js
                  JAVASCRIPT
                

                

              

              

                
require("dotenv").config();
const express = require("express");
const OpenAI = require("openai");

const app = express();
app.use(express.json());

const client = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY
});

app.post("/api/chat", async (req, res) => {
  try {
    const { question } = req.body;

    if (!question) {
      return res.status(400).json({
        message: "Question is required"
      });
    }

    const response = await client.responses.create({
      model: process.env.OPENAI_MODEL,
      input: question
    });

    res.json({
      answer: response.output_text
    });
  } catch (error) {
    console.error(error);
    res.status(500).json({
      message: "AI request failed"
    });
  }
});

app.listen(process.env.PORT || 3000, () => {
  console.log("AI Server running on port 3000");
});

require("dotenv").config();
const express = require("express");
const OpenAI = require("openai");

const app = express();
app.use(express.json());

const client = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY
});

// 1. Basic AI Chat Route
app.post("/api/chat", async (req, res) => {
  try {
    const { question } = req.body;
    if (!question) {
      return res.status(400).json({ message: "Question is required" });
    }

    const response = await client.responses.create({
      model: process.env.OPENAI_MODEL,
      instructions: "You are a helpful MERN Stack teacher. Explain technical concepts simply.",
      input: question
    });

    res.json({ answer: response.output_text });
  } catch (error) {
    console.error(error);
    res.status(500).json({ message: "AI request failed" });
  }
});

// 2. Role-Based Prompting Route
app.post("/api/role-chat", async (req, res) => {
  try {
    const { role, question } = req.body;
    if (!role || !question) {
      return res.status(400).json({ message: "Role and question are required" });
    }

    const response = await client.responses.create({
      model: process.env.OPENAI_MODEL,
      instructions: `Act as a ${role}. Provide clear answers and practical code examples.`,
      input: question
    });

    res.json({ role, answer: response.output_text });
  } catch (error) {
    res.status(500).json({ message: "Role chat failed" });
  }
});

// 3. Zero-Shot Review Classifier
app.post("/api/classify", async (req, res) => {
  try {
    const { review } = req.body;
    if (!review) {
      return res.status(400).json({ message: "Review is required" });
    }

    const response = await client.responses.create({
      model: process.env.OPENAI_MODEL,
      instructions: "Classify the review as Positive, Negative, or Neutral. Return only one word.",
      input: review
    });

    res.json({ category: response.output_text.trim() });
  } catch (error) {
    res.status(500).json({ message: "Classification failed" });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`MERN GenAI Day 1 server running on http://localhost:${PORT}`);
});
