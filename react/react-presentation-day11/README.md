# React Day 11 — Redux Actions, Reducers, and Store

A professional, classroom-ready, slide-based educational presentation designed for teaching the core triad of Redux state management to React developers.

Built with **100% Vanilla HTML5, CSS3, and JavaScript** — runs instantly in any modern web browser without npm, build tools, or local server dependencies.

---

## 📚 Presentation Overview

- **Title:** React Day 11 — Redux Actions, Reducers, and Store
- **Duration:** 45–60 minutes
- **Level:** Beginner to Intermediate
- **Total Slides:** Exactly 18 slides

### Topics Covered
1. Introduction to Redux unidirectional data flow
2. What are actions and payloads?
3. What are action creators?
4. What are pure reducers and immutability?
5. Reducers handling payloads
6. What is the centralized Redux store?
7. How actions, reducers, and store work together
8. Traditional Redux vs Redux Toolkit (RTK)
9. Creating a Counter Slice (`createSlice`)
10. Understanding auto-generated actions
11. Configuring the Redux Store (`configureStore`)
12. Connecting React components with `useSelector` and `useDispatch`
13. How the store updates the UI
14. Practical Example: Shopping Cart shared state
15. Common beginner mistakes and best practices
16. Classroom review questions and hands-on practice assignment

## 📂 Slide Directory (18 Slides)

1. **Title Slide:** React Day 11 — Redux Actions, Reducers, and Store
2. **Learning Objectives:** Clear classroom roadmap
3. **Understanding Redux Data Flow:** Unidirectional flow with interactive step visualizer
4. **What Is an Action?:** Plain JavaScript objects with `type` and `payload`
5. **What Is an Action Creator?:** Helper functions returning action objects
6. **What Is a Reducer?:** `(state, action) => nextState` pure functions and immutability
7. **Reducers with Payload:** Handling dynamic payloads (`10 + 5 = 15`)
8. **What Is the Redux Store?:** Centralized state tree and store responsibilities
9. **How Actions, Reducers, and Store Work Together:** Stepper diagram of complete update loop
10. **Traditional Redux vs Redux Toolkit:** High-clarity comparison table
11. **Creating a Counter Slice:** Full working `counterSlice.js` code with Immer explanation
12. **Understanding Generated Actions:** Mapping slice reducer names to generated action creators
13. **Configuring the Redux Store:** Full working `store.js` with `configureStore`
14. **Dispatching Actions from React:** Full working `Counter.jsx` with `useSelector` and `useDispatch`
15. **How the Store Updates the UI:** Step-by-step walkthrough of Increment by 5
16. **Practical Example — Shopping Cart:** E-commerce state structure with interactive shopping cart simulator
17. **Common Mistakes and Best Practices:** Troubleshooting guide and clean architectural habits
18. **Summary and Practice Task:** 7 click-to-reveal review questions, assignment specs, and interactive live counter simulator
