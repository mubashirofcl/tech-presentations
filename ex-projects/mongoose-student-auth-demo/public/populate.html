Mongoose populate() Method Explained

Learn how MongoDB documents reference each other using ObjectId and how Mongoose replaces foreign keys with full documents.

🧠 How Document Referencing & populate() Works Behind the Scenes

1. "students" Collection (Child)

Student Document: { name: "Rahul", enrolledCourse: ObjectId("65f...") } Schema: type: ObjectId, ref: 'Course'
→ .populate("enrolledCourse")

2. "courses" Collection (Parent)

Course Document: { _id: ObjectId("65f..."), title: "MERN Bootcamp" } Mongoose queries Course model by _id

Classroom Summary: MongoDB does not do SQL JOINs. Mongoose populate() runs a secondary internal query on the referenced collection (ref: "Course") and replaces the ObjectId in-memory before returning the JSON!
